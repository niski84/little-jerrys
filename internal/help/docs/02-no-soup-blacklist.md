# No Soup For You — the blacklist

Some episodes just don't work for breakfast service. The blacklist takes
specific files out of the random rotation entirely.

## How to use it

1. Open the admin UI from your phone or laptop.
2. Tap **No Soup For You** in the top nav.
3. Find the episode in the list and hit **Block**.

The change applies on the next reshuffle (typically within a minute, or
immediately if you press the bailout button).

## Unblock

Same page — blocked episodes show an **Unblock** button instead.

## When to use this vs. weights

- **Block:** never play this episode again.
- **Weight 0–1:** plays at the default rate.
- **Weight 2+:** plays more often (staff favorites).

If an episode is *almost* never wanted but a regular asks for it once a
month, set weight 0 — wait, weights start at 1. Block it instead and
unblock when the regular shows up.
