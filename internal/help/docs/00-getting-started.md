# Getting started

Welcome to the Little Jerry's Automator — your dedicated TV box for Seinfeld
playback during service.

## What's in the box

- A Raspberry Pi appliance you plug into HDMI and USB
- A USB thumb drive holding all the episodes (and optional commercials)
- A red arcade "Bailout" button under the bar / host stand
- This admin web app, reachable from any phone or laptop on the same network

## First-time setup

1. Plug HDMI from the Pi to the front-room TV's input.
2. Plug the USB thumb drive into any USB port on the Pi.
3. Plug the bailout button cable into the side of the Pi.
4. Plug in power. The Pi boots straight into Seinfeld within ~30 seconds.
5. If no known WiFi is available, the Pi broadcasts its own setup network
   called `LittleJerrys_Config`. See **Connecting to WiFi** for the rest.

## Day-to-day use

The Pi is designed to be invisible. Power it on in the morning, power it off
at night. Episodes pick up where they left off after a power cycle, and a
true-random shuffle ensures the same episode never plays twice in a row.

Hit the bailout button if a particular scene isn't landing — the next
episode starts immediately.
